### A bit about me

I'm a final-year IT student at IIIT Sonepat who spends most of his free time building things that touch blockchains — mostly because "how do I make untrusted parties agree on state" is a more interesting problem than most of what shows up in a normal CS curriculum.

Over the last year I've gone from writing Solidity for hackathons to actually shipping production infra:

- Built a **governance portal for Nouns DAO** during Protocol Labs' Founders Forge accelerator — real-time auction engines, proposal workflows wired straight into smart contracts, ENS-hosted so nobody can take it down. It's live for 500+ token holders.
- Wrote **stateful ICP canisters in Rust** at BlockseBlock, with per-user sandboxing so one person's bad request can't touch another person's data.
- Built Git's commit-tracking data structures **in Motoko** at CodeStep, which is a sentence I did not expect to say a year ago.

When I'm not doing that, I'm usually deep in a LeetCode contest (currently sitting around 1881) or arguing with a Redis cache config until latency numbers look right.
